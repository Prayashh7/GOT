Game of Thrones 
Live : https://gamee-of-throne.netlify.app/

A modern and immersive Game of Thrones–inspired website designed to provide users with a cinematic and engaging online experience. The website showcases the world of Westeros through a visually appealing design, smooth animations, and a dark medieval-themed interface.

## Features

🏠 Cinematic and modern homepage  
⚔️ Game of Thrones–inspired visual design  
🏰 Medieval and Westeros-themed UI  
🎬 Smooth animations and transitions  
📱 Mobile-friendly responsive design  
🎨 Attractive dark fantasy interface  
🌑 Immersive cinematic experience  
⚡ Fast and smooth user experience  
🌐 Deployed and accessible online  

## Technologies Used

React.js – Frontend development  
JavaScript – Functionality and interactions  
HTML5 – Website structure  
CSS3 – Styling and responsive design  
GSAP – Animations and transitions  
Git & GitHub – Version control  
Netlify – Deployment and hosting  

## Purpose

This project was developed as a practical web development project to create an immersive and visually engaging Game of Thrones–inspired website using modern frontend technologies, animations, and responsive design.
